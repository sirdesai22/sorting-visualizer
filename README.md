# 🔢 Sorting Algorithm Visualizer

A web-based sorting algorithm visualizer that provides a graphical representation of popular sorting algorithms in action. Users can observe each step of the sorting process, gaining insights into algorithm efficiency and complexity.

## 🚀 Features

- 📊 **Visual Representation**: Step-by-step visualization of sorting algorithms.
- 🔄 **Multiple Sorting Algorithms**: Supports Bubble Sort, Merge Sort, Quick Sort, and more.
- 🎮 **Interactive Controls**: Adjust speed, array size, and choose different algorithms.
- 📈 **Educational Tool**: Helps users understand sorting mechanics and time complexity.
- 🌐 **Responsive Design**: Works seamlessly on all screen sizes.

## 🛠️ Tech Stack

- **Frontend**: React.js, TailwindCSS
- **Framework**: React.js
- **State Management**: useState, useEffect
- **Deployment**: Vercel

## 🏗️ Installation & Setup

1. Clone the repository:
   ```sh
   git clone https://github.com/sirdesai22/sorting-visualizer.git
   ```
2. Navigate to the project directory:
   ```sh
   cd sorting-visualizer
   ```
3. Install dependencies:
   ```sh
   npm install
   ```
4. Run the development server:
   ```sh
   npm start
   ```
5. Open [http://localhost:3000](http://localhost:3000) to use the visualizer.

## 🎯 How It Works

1. **Select a Sorting Algorithm**: Choose from Bubble Sort, Merge Sort, Quick Sort, etc.
2. **Adjust Parameters**: Set array size and animation speed.
3. **Start Sorting**: Watch the sorting process step by step.
4. **Analyze Performance**: Observe comparisons and swaps.
